# 3D models

The castle models (walls, floors, barrels, crates, tables, banners, torches, food, lanterns, trees...) are from the
KayKit asset packs by Kay Lousberg (www.kaylousberg.com), released under Creative Commons Zero (CC0):
Dungeon Remastered, Restaurant Bits, Furniture Bits, Halloween Bits and the Medieval Hexagon Pack.
Each folder keeps the pack's own LICENSE.txt. Only the models the game uses are copied here.
